B — Carnet du semencier

Le même carnet de papier que l'Herbier : page de gauche le sachet, page de droite les règles écrites à la main. Cohérent avec l'onglet voisin, mais le papier clair éteint les effets de rareté (halo, lueur dorée) qui font tout le sel de l'ouverture.

C — Colonne centrée

Tout empilé dans une colonne étroite, les jauges réduites à deux barres avec le détail replié. Sobre et vite fait, mais les règles disparaissent derrière un lien, ce qui va contre le "pity visible" de la vision.
